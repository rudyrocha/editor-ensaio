# Pacote de documentação e testes — Editor de Ensaios 3.1.3

Documentação derivada da leitura dos fontes dos pacotes v3.1.2 e da atualização v3.1.3, sem modificar o editor instalado. Consulte `docs/00_LEIA_PRIMEIRO.md`.

**Instalação somente de documentos:** copiar `docs/` para `D:\OFFline\Videos\@ensaio\_sistema\docs\`.

**Testes:** executar apenas em uma **cópia** do aplicativo, colocando `tests/` ao lado de `ensaio.py`, e usando `py -3.13 -m unittest discover -s tests -v`. Não copiar testes para produção para executá-los cegamente. Não incluir diretórios `brutas/`, `referencias/` ou `processadas/` do usuário num commit Git público.

A pasta `modelos/` fornece checklist de cada nova release.
